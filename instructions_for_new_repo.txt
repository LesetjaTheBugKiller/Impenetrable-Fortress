WHAT THIS SYSTEM IS
Java HTTP service (Lichess Guard) plus MT5 Receiver (executes) and Sender
(buttons). Server owns daily loss cap, profit target, max losses, spikes,
cooldown, and "all positions at break-even". Receiver reports facts and sizes
lots from equity * risk% / stop distance. Stops are silent (virtual). Take
profit is visible on the ticket at 1:4. Daily profit target default is 6%
(expected value of four trades, 1% risk, 50% win rate, 1:4). Loss cap default
3%. Cooldown in the owner's local .env has been 0.2 minutes (12 seconds) for
testing; production example is 5 minutes. Confirm with the owner before
copying that value to the VPS.

Weekend desk: desk/keeper on the VPS opens RDP (TCP 3389) only in a weekend
window. desk/link on the home PC. Shared hours in desk/desk.env (from
desk/desk.env.example). Official tle.exe is gitignored under desk/bin/.
